# 假设与来源门禁：不是每个数都能借一篇论文背书

## 必须区分的六类

1. **题面要求**：引用英文题面页码/任务，不称统计假设。
2. **原论文方法及前提**：给作者、原文版本、准确页码/式号；核对其总体与信息集是否适用。
3. **原始数据事实**：定位月文件、字段和可复算表；样本事实不能升级为全局机制。
4. **数学定义/恒等式**：给定义域、完整推导和边界条件，不虚构某篇论文“提出”了基本代数。
5. **统计假设**：必须有提出它的依据和与本题相符的证据；文献使用过不代表本题成立。未有证据列为待建立，限制推断。
6. **工程默认值/旅客偏好/情景参数**：不得伪装成自然定律或有文献认证的常数。说明谁选择、为什么、约束是什么；无依据者撤回正式结论，保留候选必须明确其性质。

## 每条记录至少九项

ID、类别、明确陈述、来源ID、原文准确位置、必要性/本题理由、当前状态、所需证据/检验、失效后处置。见ASSUMPTION_REGISTER.csv。新参数、新筛选规则、新外推前提都要新增条目。

## 不能为了“每个假设有出处”而造出处

例如：论文介绍logistic不等于支持本题60分钟；论文做bootstrap不等于支持7天；源代码写500不等于500有精度保证；题面允许2027情景不等于赔率×3合理。敏感性可以评估依赖程度，但不能弥补来源造假或证明假设为真。

无来源时三条路径：补充可核验原文/数据证据；改写为明确的条件目标或区间；撤回依赖该假设的结论。不能把一栏统一填“经验”“常识”“已有研究”。
