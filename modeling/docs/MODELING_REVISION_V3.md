# C2701建模工作修订说明 v3：从来源到可检验结论

日期：2026-11-26。此处按“问题—原式—改造—检验—结论边界”重建论证逻辑，**不是历史先后叙事**。真实回查、失败检索和程序反例顺序见DERIVATION_LOG。审查原件与逐条回应分别见reviews和REVIEW_RESPONSE_V3。

## 1. 先固定对象，不先选漂亮的排名

观察单位是BTS Reporting Carrier月表中筛出的一个计划国内航段；机场按出发地比较，不是全部进出港，不是旅客完整行程。机场清单继承旧手册，在v3用2023真实规模、航司集中度、目的地数、时段、季节和距离表补充异质性描述。未声称全国随机抽样或事前注册选点。

审计先把记录分为取消C、改航V、正常完成K、无法可靠分类U；K再按阈值t划为长延误L_t和满意A_t。15分钟准点口径已由BTS_FIELDS原始词典核对为严格小于15；60分钟只是本项目展示长延误的候选，不能当旅客调查结论。取消、改航、字段未知与正常完成不是同一种空值。

## 2. 为什么只需要两条相连的原式

本题要互斥结局的可解释概率，但没有证据支持取消、改航、长延误三种无条件事件独立。三个互不相连的风险分数可能无法形成合法联合分布。Peyhardi等的局部分类GLM和分区条件GLM提供了适配路径。

**原式F1**来自P1原始预印本arXiv:1404.7331v2、PDF第4页§3.1：编号(1)是链接分解，随后未编号式为r(π)=F(Zβ)。符号r为概率比变换，F为连续严格递增分布函数，Z为设计矩阵。P1第5页和P2第5页允许分支设计有差异。本题二分结点取logistic F，得到q_v=σ(α_v+x_v′β_v)。logistic、线性特征和惩罚量只是可检验候选。

**原式F2**来自P2原始预印本arXiv:1405.5802v1、PDF第5页Definition 2后的未编号路径乘积：叶概率等于根到叶的条件转移概率之积。这里未杜撰公式编号，也未冒称原作者首次发明概率链式法则。F1估计乘数，F2组装整体，两式属于一条理论链。

确切版本、文件SHA256、符号与阅读定位见FORMULA_PROVENANCE。不是只引用标题或二手综述；校准与评分辅助论文另列，不增设无关核心模型。

## 3. 本题改造怎样逐步得到，而非只做验证

1. 在已知结局U=0内定义f=P(C|x)，v=P(V|非C,x)，h_t=P(延误≥t|K,x)。条件风险集分别为所有已知、已知且未取消、已知且正常完成。
2. 沿F2的路径逐项相乘：π_C=f，π_V=(1-f)v，π_L=(1-f)(1-v)h_t，π_A=(1-f)(1-v)(1-h_t)。四项相加为1；这是一种分区，不是物理事件先后，也不是严重程度排序。
3. 求满意的补集得到联合不满意风险1-(1-f)(1-v)(1-h_t)。不需要结局类别独立，不能把三个无条件概率偷换成f/v/h。
4. 将叶概率的乘积取对数，一条记录只贡献所经过结点，得到各风险集二项损失之和。论文观测独立条件不能直接照搬到共同天气/运行冲击下的航班，因此这里只用工作损失拟合，不借独立标准误作显著性保证。
5. 对U不补0、不假设随机缺失。以真条件概率写总体关系R_t=(1-u)π_A+uθ_t，θ_t∈[0,1]。经验计数的缺失识别下/上界为满意已知数/N及(满意已知数+U)/N；区间宽为U/N。**拟合模型有误差时，将估计π代入的范围并不是自动有效的总体识别界**；实证比较用计数界，不把它称95%置信区间。
6. 选共同支持内的参考构成，对各格上述满意率加权。参考权重为各机场限制到共同支持后的格分布等权平均，不是从全国权重伪推出来。改变分层意味着改变调整目标。
7. 对两机场差作加减恒等分解：全样本原始差=共同支持调整差+(共同支持原始差−调整差)+(全样本差−共同支持原始差)。第三项是支持筛选，不能全部叫构成效应；也不是已核读的Kitagawa原式。

这些改造属于统计目标和数据审计适配、既有方法组合，不是原创概率定理。没有将测试通过或少数分数改善说成原创优化已经奏效。

## 4. 审查引出的计算修复与适用边界

旧算法只按年份抽日期，真实2023样本能漏掉整个秋季，导致共同格分母为0。v3按连续年份—季节日期段做非循环移动块，同一日期权重配对给所有机场，1/7/14天分别报告。缺月和跨年不拼接；若任一标准化重复出现空格，该长度的标准化区间整体停止发布，保留点估计、失败次数和原始率区间，不重抽“直到成功”。

这解决计算故障，不证明局部平稳、弱依赖或95%区间覆盖。Künsch原作仍未取得，当前方法及条件门禁未通过，只能标实验性、固定参考权重的条件区间。多次seed和更多重复仅检查蒙特卡洛分位数波动。

2023基础共同支持24格，MCO约23.61%、HNL约98.92%。因此不能给全体航班的公平严格排名。粗分层可增加覆盖但少调了变量；路线样卡可细对航司与时段，但也会丢失不重合航班。所有解释必须同时报覆盖。

## 5. 真实预测检验如何接到同一主式

统一输入是出发/到达机场、运营航司、月份/星期、计划时刻及距离等历史计划字段。它们没有经过订票时排班快照验证，因此只称“计划字段可用性代理”，不声称真实订票时能力。未接入未来实况天气作先验输入。

在相同时间窗、同一批已知结局测试行上比较：历史分组率、直接联合logit、F1/F2条件树。联合模型直接预测同一个p_bad,t，是检验条件分解是否值得其额外复杂度的消融对照，不另成第三理论主线。模型各自只在验证期选C，随后重拟合与独立校准，15/60分钟分别拟合。三分支比一个联合模型参数预算更大，不能称完全等复杂度对照。

primary计划：2023拟合、2024Q1调参、重拟合至2024-03-31、Q2校准；之后仅评实际取得的完整月，逐月命名，绝不把2025-01叫2025全年。比较故障不阻塞预测，36个月未齐不阻止满足自己时间条件的任务。

为不空等下载，先完成2023开发计划：1—8月拟合、9月调参、10月校准、11—12月测试。这些月份未进入相应拟合/调参/校准，但分析者此前见过2023描述数据，不称研究盲测。这不是2025验证，且Q4未见历史分组会退回训练总率，不能用该弱基线差距宣称树一般更优。实验上限每二分类50000条、seed2701、C候选0.1/1/10、基线收缩20、校准C=1e6都为登记候选，非论文替本题提供的最优参数。

Brier、log loss、观测/预测率、可靠性图、分支事件数及机场/时段/航司失效分组共同报告；分支各自校准不自动保证联合校准。最终成绩和实际月份以results/review_v3中的status与数据快照为准，不预写“低估”方向或胜出者。

## 6. 困难日检验不再用结果定义证据

按测试日实际失败率挑尾日，会选择性纳入正残差；只保留为RETROSPECTIVE_OUTCOME_SELECTED描述。独立窗口采用GOAA会议材料PDF93—94页明确的MCO应急中心2024-10-09至10-10一级全面激活。不是全机场关闭证据，不把NHC UTC登陆直接当机场本地FlightDate。

对照用相邻同星期日期，是日历对照而非已核实平静天气；在目的地/航司/时段/星期共同格中以事件构成加权，报告覆盖及观测—预测，不对两天事件制造稳定95%置信保证或因果归因。IT官方候选404，本轮不当已核实事件。任意2027赔率倍率继续默认关闭。

## 7. 旅客样卡与监测：有证据的部分先交

正确案例是**EWR或LGA出发、去DEN**，不是DEN出发。先列全部计划分母的取消、改航、正常完成≥60分钟和联合率，再按共同航司×季节×时段匹配；显示覆盖、成对差值、1/7/14天实验区间及后来已取得月份。取消差很小时应说证据不足，而不是强行给偏好权重。地面交通、票价、改签与错过衔接缺数据，不据此给完整门到门效用排名。

监测按“新月度数据到达”触发重新审计，是工作流程而非统计保证；发布前核对来源指纹、未知率、共同支持覆盖、时间泄漏和分组校准。出现来源指纹不符、目标域不重叠或时间泄漏，应停止对应结论。概率漂移报警阈值、偏好风险预算和再训练频率没有依据时保留待定，不虚构通用红黄绿线。
