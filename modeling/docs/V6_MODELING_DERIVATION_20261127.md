## 1. 从题面与指标缺口开始，而非再堆模型

题面原件在 `problem/`，原阅读及指标筛选见 `EVALUATION_FRAMEWORK_V4.md`及配套指标台账、`FORMULA_PROVENANCE.md`。难点不是单独预测完成后的延误，而是取消时延误结构性不可定义，改航、缺失与不同阈值又须有共同分母。应先定义取消、改航、完成且长延误、条件长延误、联合不满意和未知结局，再检查数据能否支撑；不能因为手头有某列就制造新指标。

新增问题来自19个既有留出月的真实反例：分别拟合的15/60分钟风险虽可分别评分，却未必来自同一个结局分布。旅客同卡展示必须满足 `p15 >= p60`。本题改造聚焦这个**结构一致性难点**，不宣称改造必然提高评分。

## 2. 原式、版本、页码与适用前提

仅用下面两条核心预测式，辅助校准与评价不提升为第三套核心模型。

### F1：先估计树的局部条件概率

P1：Peyhardi, Trottier, Guédon，*A new specification of generalized linear models for categorical data*，arXiv:1404.7331v2，本地 `literature/PEYHARDI2014_SPEC.pdf`，共32页。
原文 PDF p4 §3.1 编号(1) `g_j = F^{-1} ∘ r_j`，其后未编号式 `r(π)=F(Zβ)`；p5 §3.2 给出设计矩阵与不同系数约束。

- 原符号：π为类别概率，r为概率比变换，F为连续严格递增分布函数，Z为协变量设计，β为系数。
- 原条件：链接在其概率单纯形内部可逆；原p4还假定给定协变量的观测条件独立。**本项目没有证明航班满足后一条件**。
- 本题适配：每个局部结点都是二分，选择logistic分布函数，使 `q_v=σ(α_v+x_v'β_v)`。函数族有原论文的方法依据；采用线性、选哪些协变量、C值与样本上限，均不由原论文替本题证明。

### F2：再把正确风险集的局部概率组合为整体分布

P2：同作者，*Partitioned conditional generalized linear models for categorical data*，arXiv:1405.5802v1，本地 `literature/PEYHARDI2014_TREE.pdf`，共25页。
原文 PDF p5 Definition 1：兄弟结点是不相同且覆盖父结点的分区；Definition 2：每个非终端结点有局部GLM；其后**未编号**的类别概率路径乘积式。用等价简记：

`π_j(x) = ∏_{e∈path(root→j)} P(child_e | parent_e, x_parent)`。

- 原符号：T为分区树，v为非终端结点，Ch/Pa为子/父结点；局部 `π^v_j=P(Y∈Ω^v_j|Y∈v;x_v)`。
- 原条件：兄弟事件互斥且覆盖父集；每个结点概率对应自己的条件风险集。
- p7式(3)及p8分别估计的讨论支持在**没有共享系数约束时**分解拟合；“独立方程”是可识别性/维度概念，不是航班之间独立的实证证明。
- P1/P2于2026-11-26已完整阅读（含参考文献，P1含附录）；本轮重读关键页，不冒称重新逐字重读两篇全文。SHA见 `literature/SOURCE_MANIFEST.json`。

## 3. 为什么采用这一棵树：由分区要求逐步得到

先把字段冲突/无法判定归未知 U，不能偷偷按取消或改航优先。下式仅针对 `U=0`；I表示**共同可用信息集**。I相同是同卡分布解释的条件，不等于已经证明购票时实际获得了每个输入。

设 C取消，V非取消中的改航，K非取消且非改航的正常完成，D为K内到达延误。按60再细分15分钟，是为了保留已选60分钟树的既有前三个局部分支，并新增一个小于60分钟内部的分支；这是本题工程适配，**不是P2规定此种切分顺序最优**。

|局部概率|目标与风险集|估计依据|
|---|---|---|
|f|P(C\|I,U=0)，所有已知结局|F1；取消标志|
|v|P(V\|非C,I,U=0)，所有非取消已知结局|F1；改航标志|
|a|P(D≥60\|K,I,U=0)，所有正常完成|F1；到达延误|
|b|P(15≤D<60\|K,D<60,I,U=0)，正常完成且小于60|F1；新增条件分支|

四次二分类必须分别在这些风险集中拟合和校准，不能把四个无条件分类概率塞进乘积。实现对应 `src/joint_candidate_v6.py` 中 `SharedFiveLeafModel`、`observed_leaves` 与风险集计数；测试检验风险集标签与概率闭合。

## 4. 将 F1 放入 F2，逐叶推出双阈值

依次经过树的相应路径：

```
πC       = f
πV       = (1-f)v
π60      = (1-f)(1-v)a
π15_60   = (1-f)(1-v)(1-a)b
πunder15 = (1-f)(1-v)(1-a)(1-b)
```

证明闭合，不靠样本迭代验证：后三项括号 `a+(1-a)[b+(1-b)]=1`，再上卷为 `f+(1-f)[v+(1-v)]=1`。局部分支在[0,1]内时五叶非负且和为1。

题面的联合不满意由互斥叶相加，而不是额外预测式：

```
p60 = πC+πV+π60
p15 = p60+π15_60
p15-p60 = (1-f)(1-v)(1-a)b ≥ 0
```

这说明**只要同一五叶用于两个阈值**，结构上就不倒置；它不要求C、V与延误独立，不保证概率准确或2027可迁移。未知结局仍按原 `FORMULA_PROVENANCE.md` 的识别界处理，未知率u时无插补区间宽度为u；不可因为核心数据只有1条未知便把MAR当事实。

反向看，任意两条独立边际若 `p60>p15`，隐含的中间叶质量 `p15-p60` 为负，不可能构成这一共同分布。逐项 `clip` 或换成 `min(p60,p15)` 虽能修边际，却引入事后调整，也不给出完整、经评分的联合模型；本轮不把这种捷径当已验证方案。

## 5. 从路径乘积到拟合/校准：把合理性与尚未证明分开

对第i条记录只累计其经过结点的二元交叉熵，是对F2叶概率取log后重排。没有跨结点共享系数时可分别优化。原论文的观测条件独立前提未在航班数据中证实，故这里是工作损失/点预测算法，不从它直接推出独立标准误、显著性或严格区间。

v6冻结：拟合2023-01-01至2024-03-31，校准2024-04-01至06-30，四个分支C=0.1，每分支上限50,000，seed2701。C是倒正则强度；上限是算力选择，**不是原论文最优参数**。原有选模/调参时间线见v5协议；新候选复用了既有结果已可见的窗口，不重新标成预注册。实际每个分支正例数、校准数、告警全部保留在candidate_status及delivery_status。

校准用独立时间段风险集上的 `σ(γ0+γ1 logit(clip(q)))`。CAL2005原始实证论文已全文补读，p2 §2.1式(1)-(3)支持sigmoid分数映射与分开校准样本的考虑；它是该作者自己的实验，不是已读Platt1999原作。原文式(3)是pi定义，不是目标平滑公式。本实现clip=1e-6、C=1e6不是原文确定的参数。

不发生clip时，`logit(q)=α+x'β`，所以校准后仍可写为 `σ[(γ0+γ1α)+x'(γ1β)]`；这是代数重参数化，不是新增第三核心公式。发生clip时是带边界截断的工程扩展；γ1也未由文献保证为正。校准局部分支后再用F2，可保持结构闭合；**不能据此宣布分支、叶或联合概率已校准**。更多定位及限制见 `AUXILIARY_FULL_READING_V6_20261127.md`。

## 6. 历史旅客卡不是五叶预测卡

历史卡只用2023–2025年EWR/LGA→DEN的24,023条已取得计划航段作结局频率与共同支持比较，不是候选的逐航班预测，更不是2027购票实时卡。

- 以 `Reporting_Airline × season × time_bin(6小时)` 分格，**称报送航司字段**，不能未经字段核验写成运营航司。冻结v6叙述里旧措辞保留为历史，当前生成器更正措辞不改数字。
- 两机场每格至少30已知结局是工程门槛；池化共同格12个，跨年固定共同格9个；30、6小时和分格充分性均没有被P1/P2证明。
- 支持内每机场计划构成各归一化，再对两机场构成取平均作为参考权重。对每叶做相同加权，再派生联合风险和条件风险。条件长延误须用“标准化长延误联合质量 / 标准化完成质量”，不能直接把每格条件率等权平均。
- EWR支持9,533/9,572=99.59%；LGA支持6,267/14,451=43.37%。结论只对这个共同支持和选定参考总体成立；不推导全体LGA更好或机场因果作用。
- 取消调整差7日实验区间跨0，不选“取消冠军”；在已观察支持总体内，LGA长延误较低是描述性比较，不保证具体选项或未来表现。
- 区间在固定支持和权重条件下作日期配对区块重采样，1/7/14日、1000次、seed2701。尚未证明区块长度合适或覆盖率有效；敏感性不能替代来源与依赖假设。

实际工件：`traveler_card/route_rates.csv`、`support_coverage.csv`、`reference_weights.csv`、`matched_comparisons.csv`、`card_status.json`。原始率、池化调整率与固定跨年调整率各有自己的分母/范围，不混用。
