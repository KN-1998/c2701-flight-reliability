# 从两条原式到双阈值一致性：推导与可撤回的候选

2026-11-27。触发原因是用户报告v5对15/60分钟分别选择不同模型；这是验收后追加的检查，不写成事前预注册。

## 1. 原式、定位与前提
P1：Peyhardi、Trottier、Guédon，A new specification of generalized linear models for categorical data，arXiv:1404.7331v2，PDF p4 §3.1式(1)给出链接分解，其后未编号式为r(π)=F(Zβ)；p5讨论设计矩阵与共享/非共享斜率。二分结点适配为q_v(x)=σ(α_v+x_v′β_v)，仍为F1。原文p4有观测条件独立假设；本项目未证明航班条件独立，不据此给iid显著性保证。

P2：同三作者，Partitioned conditional generalized linear models for categorical data，arXiv:1405.5802v1，PDF p5 Definition 1/2后未编号式，将根到叶的局部条件概率相乘，仍为F2。pp7–8解释可分解估计的条件：不同结点无共享回归系数时可分别最大化。原式不是编号“式5”，也不是航班事件独立或先后因果的依据。

本轮重查本包原PDF上述页并渲染核对公式；不是新增全文阅读。原全文阅读记录仍在PRIMARY_FULL_READING_NOTES_V3.md。本页后续均为F2的本题代数推导，不把它们杜撰成原论文专门研究航空阈值的公式。

## 2. 从同一结局分区推导，而非从结果倒推
在相同已知结局总体U=0、同一预测信息I下，定义C为取消，V为非取消的改航，K为正常完成；D为K内到达延误。
B_t=C∪V∪(K∩{D≥t})，三部分互斥。由F2及既有D1/D2，令f=P(C|I)，v=P(V|非C,I)，h_t=P(D≥t|K,I)，则

    p_t=f+(1-f)v+(1-f)(1-v)h_t
       =1-(1-f)(1-v)(1-h_t)。

若相应条件风险集概率为零，下游条件概率不可识别；全局质量为零的分支不贡献叶概率，不能据此声称该条件模型可估计。

因为{D≥60}⊆{D≥15}，B_60⊆B_15。两者相减：

    p_15-p_60=(1-f)(1-v)(h_15-h_60)
             =P(K,15≤D<60|I)≥0。

这是同一概率分布中的集合恒等式，不需要独立航段、事件无条件独立、同一损失偏好或新增统计分布假设。其前提是总体、信息时点和事件定义相同。跨航段、跨信息集、跨不同有效分母的两个概率不适用这种逐项比较。

## 3. 为什么分别选优后还要检查
独立拟合的两阈值模型，或15分钟用直接模型、60分钟用树模型，未必是同一个联合分布的两项边际。各自Brier较好不能在逻辑上保证逐航段p_60≤p_15。
检查不是宣称实际发生倒置。threshold_coherence.py按稳定航段键对齐，并检验标签/元数据，然后对三种同方法组合及“低阈值直接、高阈值树”逐月和总体统计p_high-p_low>1e-12。容差只是浮点工程默认，不是旅客无差异范围；输出原始最大差，不修剪概率。

若存在倒置：先核身份、阈值、有效分母及时间戳；保留冻结预测和失败例；不在已见测试上修完后再称盲测提升。若无倒置，也不构成所有未来航段均一致的定理。

## 4. 可选的结构适配：仍只用F1/F2（未训练、未替换v5）
只有若需要统一双阈值分布且资源允许，才考虑将K继续划为≥60、[15,60)、<15三个互斥叶。
设a=P(D≥60|K,I)，b=P(15≤D<60|K,D<60,I)。把a与b分别作为F1的二分结点，F2给出五叶：

    C: f；V: (1-f)v；
    K且D≥60: (1-f)(1-v)a；
    K且15≤D<60: (1-f)(1-v)(1-a)b；
    K且D<15: (1-f)(1-v)(1-a)(1-b)。

这五项非负且求和为1；h_60=a，h_15=a+(1-a)b，因此结构上p_15≥p_60。得到的是PCGLM的本题适配，不是原创概率公式。
代价是由3个二分模型增为4个，增加拟合/稀有风险集问题，约束也可能降低单口径表现。需新的真实冻结方案、同特征和参数预算对照、充分风险集、独立后续评估；**本轮未训练此候选，也未发现必须用它替换v5的证据。** 不能把结构一致性称性能优化已成功。

## 5. 异常事件的另一项派生核对
同一事件期、同一已知航段分母内，B_t包含取消，故经验联合不满意率至少为经验取消率。
按用户报告整数，2139/5458≈39.19%；报告60分钟联合率76.36%与该界相容。报告三模型均值10.16%—11.77%不仅远低于联合率，也低于观测取消率。用报告的舍入值计算，联合率低估约64.59—66.20个百分点。

这些是**收到摘要后的算术解释，不是独立事件重算**；未从76.36%反造整数事件数，不杜撰窗口、机场范围或原因。预测与实际率不同是实证失效，不等于预测内部违反p_bad≥f，因为模型自身的预测取消率不一定是观测取消率。不能用未知冲击赔率倍率“校正”成拟合事件后的成功。
