# 真实建模过程与检索记录

记录日期2026-11-26。目的：让编程手/写作手能复现“为什么走到这个公式”，而不只看它是否在样本上好用。

## 0. 时间真实性

v1先实现了条件概率链、共同支持标准化和工程默认值，随后用户要求来源先行。本轮是在这个事实基础上的回溯纠偏，不把后查文献改写成最初先读论文。先前所谓“预先参数”只表示代码默认，不能等同登记过的预注册方案。后续候选及修改从本文件留下版本记录。

## 1. 从题意提取约束，而不是从模型名出发

英文题面第2页任务1要求保留取消/改航和未知，因此不能只回归已完成航班延误；任务3要求联合风险和分项风险，因此需要能组成一个分布而不重复计数的结构；任务2要求公平比较，因此对共同构成积分，而不是直接把不同分母的排名当性能。

## 2. 检索路径与选择理由

1. 以sequential/continuation-ratio/partitioned categorical model检索。最初尝试题名“A general framework for ordinal regression models”，arXiv API准确题名匹配无结果；没有把猜测题名写入参考文献。
2. arXiv按Tutz+sequential检索找到作者2020论文2010.01382v1并下载。它有条件二分解释，但主要针对项目反应模型，不直接搬用其能力参数/阈值，也不把回顾性分类论文冒充最早方法原作。
3. 按作者Peyhardi查询，找到1404.7331v2与1405.5802v1。核对PDF首页作者、版本、关键页。P2 Definition 2直接定义一般分区树，支持名义/部分有序类别，更贴近取消/改航非天然序数的情况，因此选P2作树构造主来源；P1支持局部GLM分解。
4. 试图核对Kitagawa(1955)。Crossref元数据确证作者、题名、期刊、卷页和DOI；出版社PDF403、JSTOR429、大学候选地址超时。**未读全文，不引用其具体公式或页码。** 原代码差距分解改为可逐项证明的D7，不假装完成了Kitagawa原式复现。
5. 试图核对官方BTS阈值页面，本轮403；没有升级为正文已核验。已下载月数据中的ArrDel15与ArrDelay≥15对账可支持本样本一致性，但不能替代定义词典的原文证据。
6. 保存实际下载成功/失败的URL、状态、文件哈希及原论文元数据；见literature/README.md及FETCH_LOG文件。网页搜索工具本轮没有返回可读内容，实质核验来自直接下载原文，不编造搜索引文编号。

## 3. 阅读后的取舍，不只摘一个好看的式子

- P1/P2支持“局部条件模型→整体互斥分布”；不支持本题三个事件无条件独立，也不支持取消比改航严重。
- 不照搬P1的条件独立观测作为数据事实；共同日期冲击使其至少需要弱化为工作损失。
- 不用参数自由度更多就宣称更优；保留透明基线和分支共享/不共享对照。
- F1/F2本身不是本题原创。当前改造属于审计总体、缺失界和参考构成的适配，收益尚待实证。
- 不用其他论文里同样出现“7天”“60分钟”就充当本题取值依据；具体人口、信息集和目标必须对应。

## 4. 推导过程与代码发现

先检查四叶分区与风险集，再将F2特化为D1；验证概率和并求补集得D2；由对数乘积得D3；由未知分割得到D4及识别界D5；对共同参考构成取平均得到D6。

回查实现发现：
- 原比较模型把全样本raw与限制共同支持后的adjusted直接相减命名mix，含有支持筛选项；修订为D7三项对账。
- 15分钟比较与60分钟预测不是同一个目标；在编程手完成阈值参数化/双目标拟合前，不得混写。
- 文档说2400“保留跨日标记”，代码实际上只转午夜分钟，没有输出跨日标记。该细节已列为待修，不能声称实现已覆盖。
- 默认2027倍率没有经验强度依据，已设为显式实验选项；默认历史诊断不自动生成该表。

## 5. 还没解决的，不写成已经解决

统计假设：未来迁移、函数形式、区块依赖处理、稀疏格可靠性仍待证据；工程选择：抽样上限、正则化网格、收缩强度、分层切点需配置化与敏感性；事件归因/天气时间戳仍待核验；Kitagawa全文未取得。

当前仅16个月，主实证仍PARTIAL_CORE。论文原文已读和数值测试通过，不意味着这些统计假设被证实。后续修改必须追加：触发证据、公式变化、受影响数据/结果、放弃的替代方案和剩余不确定性。
