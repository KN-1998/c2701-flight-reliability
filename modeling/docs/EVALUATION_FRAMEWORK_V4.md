# 指标优先的评价框架与两公式闭环

**这是v3数据和结果已见之后的补审（2026-11-27），不是事前注册。** 候选清单不是声称穷尽全部航空指标；它覆盖题面任务和本轮已读官方字段/原文可支持的候选。继续查到新指标应保留新增时间。

## 研究顺序及筛选理由
1. 题面p1—2先确定评价对象：计划航段能否正常完成并在容忍范围到达；不能以“已到达航班平均延误”代替全部可靠性。
2. BTS字段字典先确认 Cancelled/Diverted、ArrDelay、ArrDel15、DivReachedDest/DivArrDelay、计划与实际时刻；区分指标定义与数据报送覆盖。
3. 再检查是否存在真实数据和目标匹配的分母，不因缺数据创造伪连接损失/票价/旅客效用。
4. 原始PCGLM论文提供一致的局部分支→整体结局，不给机场公平排名或特定参数的自动保证。
5. 已有预测必须用评分、校准、分支事件数、跨期和独立冲击来质疑，而不是只保留有利指标。

## 分类而不相加
|层|保留指标|用途|为什么不和其他层加成总分|
|结局层|取消、改航、完成条件延误、全部计划中的成功率/联合风险|面向计划航段可靠性|分母与互斥性要先解释；偏好权重未知|
|可比性层|共同支持覆盖、原始/支持内/标准化差及构成分解|说明比较针对谁，检验聚合反转|覆盖是可信范围不是航班表现|
|预测验证层|Brier/log loss、校准、事件数、AUC/AP、逐月和冲击误差|检验概率模型|误差分数不是旅客体验指标|
|上下文层|季节、时段、航司、目的地/距离、天气信息时点|设计分层与解释|协变量不是新价值指标，不作因果归因|
|暂缓层|误机损失、重订成本、完整行程、票价效用|提出采集需求|当前缺少旅客级链接和偏好证据|

## 公式衔接
沿用 FORMULA_PROVENANCE.md 原文定位：F1为局部q_v=logistic(alpha_v+x_v beta_v)，F2为沿树路径相乘。
本题 f=取消概率、v=未取消中改航概率、h_t=正常完成中延误≥t概率，则四叶是 f、(1-f)v、(1-f)(1-v)h_t、(1-f)(1-v)(1-h_t)。
联合不满意风险是前三叶和，也等于1减第四叶；这是F2的代数特化，无需取消/改航/延误独立。原式支持结构，不支持本题logistic、特征、正则化、抽样上限的全部真实性。
未知结局在描述中给识别范围，在预测中明确排除并披露。标准化只是在明示支持内对同一叶概率作固定权重混合，不新增“机场本质质量公式”。

## 稀有事件校准为何改
原0—10%箱会把大多数低取消/改航概率聚到一起，但不能据此断言所有旧结论错误。Dimitriadis等 arXiv:2008.03033v1 PDF p2及p4图2讨论箱选择不稳定，p5给PAV诊断，p9表1与式(1)—(3)给评分分解，p8明确独立/至少可交换前提。
v4同时给粗箱、低风险细箱、同值不拆分分位箱及PAV描述，所有层给n和事件数。细箱边界和10分位是工程展示选择，不由论文指定；PAV是已有方法应用，不是第三个核心预测模型。
PAV在测试结局上拟合仅描绘校准及同样本分解，不改变发布预测、不据此选择参数、不把差值当样本外改善；航班相关性未解决，不给独立航班置信带。

## 因缺失而不能得出的结论
缺月未补齐不能写年度趋势；未知不随机不能自动完整案例无偏；实际天气不能替代购票时天气预报；公司全网统计不能替代本样本计数。指标筛选结果及不可计算原因见两个CSV台账。
