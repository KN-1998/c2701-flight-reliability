## 4. 同卡候选仍从F1/F2构造，不加第三主模型
使用既有THRESHOLD_COHERENCE §4的五叶共享分区。a=P(D≥60|K,I)，b=P(15≤D<60|K,D<60,I)，F1拟合四个局部二分结点f,v,a,b；F2给出：

    πC=f；πV=(1−f)v；π60=(1−f)(1−v)a；
    π15_60=(1−f)(1−v)(1−a)b；π<15=(1−f)(1−v)(1−a)(1−b)。
